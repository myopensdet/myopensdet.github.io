# Definition of Done: the testing part

A story is **done** only when every box is ticked. Agree it with the team once,
then check it on every story. "Done, except testing" is not done.

- [ ] Every acceptance criterion has at least one test, and they pass
- [ ] The tests are automated where it's worth it, and merged with the code
- [ ] The tests run in the pipeline, and the pipeline is green
- [ ] Error cases from the criteria are tested, not only the happy path
- [ ] Explored by hand for 15 to 30 minutes beyond the criteria
- [ ] Bugs found are fixed, or raised with the product owner's agreement to leave them
- [ ] Works in the test environment, not only on a developer's computer
- [ ] Test notes are on the ticket: what was tested, what wasn't, and why
