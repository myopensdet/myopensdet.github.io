# SHOP-420: Discount code at checkout

As a shopper, I want to use a discount code at checkout, so that I pay less.

## Acceptance criteria

- The shopper can enter a discount code on the checkout page.
- A valid code reduces the total.
- Invalid codes should be handled properly.
- The total updates quickly.
- Codes for shipping, gifts, etc. also work.
