# Story: refund request

As a customer, I want to request a refund for an order, so that I get my money back quickly.

## Acceptance criteria

1. A customer can request a refund for recent orders from the "My orders" page.
2. Refunds should be processed fast.
3. The customer gets an email when the refund is approved.
4. Items bought on sale may not be refundable.
5. The money goes back to the original payment method (card, PayPal, etc).
6. Errors are handled properly.
