# Template Index: Every Test Template and Script on the Site, in One Place

You need a bug report template, a pytest fixture or a release checklist **now**, and you don't remember which lesson had it. This page lists every template file on the site, grouped like the menu, with one line saying what each file is.

!!! tip "How to use this page"
    1. Press ++ctrl+f++ (++cmd+f++ on a Mac) and type what you need: `checklist`, `fixture`, `bug`, `workflow`.
    2. Open the topic, then the file. **The file link** opens it on GitHub: copy it from there with the copy button.
    3. **Open the guide** to see how to use it, step by step, with real outputs.

Every template starts with a credit line. Keep it if you share the file; change everything else for your own app.

This list is built from the files themselves by a script, every time the site is checked. It can't go out of date.
