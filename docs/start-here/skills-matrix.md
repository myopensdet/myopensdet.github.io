# SDET Skills Matrix: Every Testing Skill in One Checklist

This page lists every skill SDETs use at work, grouped by area, with a link to the lesson that teaches it.

!!! info "In plain words"
    Think of this page as a map of a big city. Each area has its own streets to learn.
    You tick the ones you already have, and the empty boxes show you where to go next.

!!! note "Before you start"
    You don't need to know anything to use this page.
    An **SDET** (Software Development Engineer in Test) is a tester who writes code to test software.
    If that is new to you, read [The SDET role](../think-like-a-tester/the-sdet-role/index.md) first.
    Words you don't know are explained in the [Glossary](../glossary.md).

## How to use this checklist

1. Pick the area you need today, or start at the top. Tick every skill you can already do without help.
2. The first empty box is your next lesson. Click its link.
3. Inside each area, the skills people usually learn first come first.

You don't need to finish one area before you look at the next. Real people learn in a messy order, and that is fine.

## How we built this list

We used three sources, so the list reflects real jobs and not just our opinion.

**1. Our own lesson plan.** Every topic planned for this site.

**2. 58 real job ads, read in November 2026,** for testing and test automation roles of every kind.
They came from companies in the USA, Canada, India, Pakistan, Poland, Romania, Denmark, Spain, Ukraine, Costa Rica, Hong Kong and other parts of Latin America and Europe.
We collected open ads from the public job boards of those companies, then counted how many ads mention each skill.
The scripts we used are in [`scripts/research/`](https://github.com/myopensdet/myopensdet.github.io/tree/main/scripts/research), so anyone can repeat the count.

**3. Public testing syllabi.** The [ISTQB Certified Tester Foundation Level v4.0](https://istqb.org/certifications/certified-tester-foundation-level-ctfl-v4-0/) and the [ISTQB Test Automation Engineering v2.0](https://istqb.org/certifications/certified-tester-advanced-level-test-automation-engineering-ctal-tae-v2-0/) syllabi.
ISTQB (International Software Testing Qualifications Board) is the group behind the most common testing certificates.

!!! tip "Read the numbers as a rough guide"
    We counted keywords, so an ad that says "API" for another reason still counts.
    Treat "in 79% of ads" as "very often asked for", not an exact number.
    Job ads also change every month. We repeat this count before every big update.
