# Start Here

New to test automation? Welcome. This is the right place to begin.

By the end of this section you will have a computer ready for testing, enough
Python to write a test, and your first tests running on your own machine.

## What you need

- **A computer** with Windows, macOS or Linux. A normal laptop is fine.
- **About an hour** for the setup, once.
- **No coding experience.** Every step shows exactly what to type and what you
  should see.

Everything here is free. You never need to make an account to learn.

## Your first three steps

Go in this order. Each step takes you to the next one.

<div class="zts-route" markdown>

1.  **[How to use this site](how-to-use-this-site/index.md)**

    How lessons work, and which learning path fits you.

2.  **[Set up your computer](environment-setup/index.md)**

    Install Python, VS Code and Docker, step by step.

3.  **[Learn Python for testing](../programming-for-testers/index.md)**

    Just enough Python to write real tests. Skip it if you already code.

</div>
